# SQL: ZOMBIE LAB — OUTBREAK

Колледж студенттеріне арналған қазақ тіліндегі SQL survival ойыны. 12 негізгі миссия және өздігінен зерттелетін құпия 13-миссия бар. SQL командалары браузердегі нақты SQLite деректер қорына орындалады; сұраныс нәтижесі мен кестелердің күйі тексеріледі. Әр миссияда SQL нәтижесінен кейін зертхана объектілерімен тікелей әрекет жасау керек.

Ойын басталғанда кіріспе көрінісі, әр миссияның соңында жеке анимациялық сахна көрсетіледі: генератор қуат алады, карантин есіктері жабылады, робот жүреді, қақпа ашылады. Бұл браузердегі CSS/3D анимациялар; дайын видео файл емес. Қате әрекет дабыл эффектін шығарады. Үш деңгейлі көмек тек ишара береді, дайын SQL жауабын көрсетпейді. JOIN тақырыбы әзірге ойыннан алынды: қызметкерлер мен рұқсаттар WHERE/IN арқылы анықталады.

## Іске қосу

Node.js 20.19+ немесе 22.12+ орнатылған компьютерде:

```bash
npm install
npm run dev -- --host 127.0.0.1
```

Терминалда көрсетілген `http://127.0.0.1:5173/` мекенжайын браузерде ашыңыз. Windows-та `START_WINDOWS.bat` файлын екі рет басуға болады. Интернет бірінші рет пакеттерді орнатуға қажет; одан кейін ойынның SQL деректері осы браузерде жергілікті сақталады.

## Дайын жинақ

`dist/` — өндірістік жинақ. Оны кәдімгі статикалық веб-серверге орналастырыңыз. `index.html` файлын тікелей `file://` арқылы ашуға болмайды: SQLite WASM жүктеу үшін HTTP керек.

## Басқару

- SQL редакторында команда теріп, «КОМАНДАНЫ ОРЫНДАУ» немесе Ctrl+Enter басыңыз.
- Бірінші миссияда SQL арқылы GEN-02 анықталғаннан кейін оны басып, тұтқасын сырғытыңыз (немесе «ТҰТҚАНЫ ТАРТУ» басыңыз), содан кейін UPDATE орындаңыз. Әр миссияда SQL-ден соң жарқыраған нысандарды басып, әрекетті аяқтаңыз.
- «СХЕМА» арқылы кестелер мен бағандарды қараңыз.
- Картаны тінтуірмен айналдырыңыз және масштабтаңыз. WebGL жоқ браузерде динамикалық иллюстрация көрсетіледі.
- 35, 40 немесе 45 минуттық шекті «ПАРАМЕТРЛЕР» бөлімінде таңдаңыз.
- Барыс браузердің localStorage жадында сақталады. Өзге компьютерге автоматты көшпейді.

## Технологиялар

React, Vite, Three.js / React Three Fiber, sql.js (SQLite WASM). Деректер серверге жіберілмейді.
